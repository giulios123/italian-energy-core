# Contributing

Grazie per il contributo. Ogni cambiamento significativo deve partire da una spec o da un aggiornamento della spec attiva.

## Flusso

1. Descrivere contesto, requisiti, invarianti e acceptance criteria nella spec.
2. Aggiungere o aggiornare test, inclusi edge case e regression test.
3. Implementare il minimo necessario nel dominio.
4. Eseguire Ruff, mypy, pytest con coverage e pre-commit.
5. Aggiornare ADR e Memory Bank quando cambia una decisione o lo stato del progetto.

Non committare bollette, POD, dati personali, credenziali o snapshot raw non autorizzati. Usare fixture sintetiche o anonimizzate.
