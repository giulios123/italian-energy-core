# Domain glossary

| Italiano | API canonica | Significato |
| --- | --- | --- |
| Fornitura / punto di fornitura | `SupplyPoint` | Punto e caratteristiche rilevanti per la fornitura elettrica. |
| Profilo di consumo | `ConsumptionProfile` | Bucket temporali di energia consumata. |
| Tariffa fissa | `FixedTariff` | Prezzi noti per validità e fascia. |
| Tariffa indicizzata | `IndexedTariff` | Prezzo derivato da indice e formula tipizzata. |
| Provenienza | `Provenance` | Origine, versione, efficacia e digest di un dato esterno. |
| Componente di costo | `CostComponent` | Riga calcolata in un breakdown. |
| Raccomandazione | `Recommendation` | Interpretazione separata del confronto economico. |
