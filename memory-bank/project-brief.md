# Project brief

`italian-energy-core` è una libreria Python open source, domain-first e deterministica per modellare, simulare e confrontare offerte di energia elettrica in Italia.

La v0.4.0 locale implementa il domain core, pricing fixed/indexed e un Billing
Engine data-driven; non dichiara copertura normativa domestica certificata finché
il golden oracle privato non è fornito e riconciliato.
