# Golden fixtures

Il repository contiene fixture sintetiche pubbliche per la Spec 004 e un ruleset
normativo pubblico limitato al proprio periodo di efficacia. Il primo oracle
reale resta privato in `private/golden-bill-domestic-bt-resident.json`; il
verificatore dedicato deve passare prima di dichiarare certificata la copertura
domestica. Un riepilogo di bolletta senza elementi di dettaglio non è sufficiente.
