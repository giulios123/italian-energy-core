# Golden fixtures

Il repository contiene fixture sintetiche pubbliche per la Spec 004 e ruleset
normativi pubblici limitati ai rispettivi periodi di efficacia. Gli oracle reali
restano privati in `private/golden-bill-domestic-bt-resident.json` e
`private/golden-bill-domestic-bt-non-resident.json`; il verificatore dedicato
deve passare prima di dichiarare riconciliato il relativo intervallo. Nessun
dato personale o documento privato entra nelle fixture pubbliche.

Per la Spec 008, le fixture source-faithful minime sono incorporate nei test e
non costituiscono una copia del catalogo commerciale. La fonte da attribuire è
la [sezione Open Data del Portale Offerte](https://www.ilportaleofferte.it/portaleOfferte/it/open-data.page),
gestita da Acquirente Unico; i bytes live non vengono committati.
